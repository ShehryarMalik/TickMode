# Installation

## Download

1. Open the [TickMode releases page](https://github.com/ShehryarMalik/TickMode/releases).
2. Open the release you want.
3. Download the APK attached to that release.
4. Open the downloaded APK on your Android device.
5. Allow installation from that source if Android asks.
6. Open TickMode.

Only download APK files from the project's official GitHub repository.

## Updating

Download and install the newer APK over the existing installation.

Updates must be signed with the same release signing key. Installing an APK signed with a different key over an existing installation will fail.

Avoid uninstalling TickMode when updating, because uninstalling removes local session history and settings.

## First launch

Allow notifications when prompted. TickMode uses an ongoing notification to show an active session and provide session controls.

Review the background setup guide before relying on sessions with the screen off.

## Installation from a development build

Debug builds use a different signing certificate from the official release APK. Switching from a debug build to the official release may require uninstalling the debug version first. This removes its local data.
